extract_compressor
/obj/machinery/extract_compressor

Squishes slime extracts together into a crossbreed. Costs biomass.

Vars

color_extractsExtracts feeding the crossbreed's color half.
cycle_biomass_costBiomass the current cycle will cost. Set when a cycle starts.
cycle_lengthTotal deciseconds the current cycle needs. Set when a cycle starts.
cycle_progressDeciseconds accumulated into the current cycle.

extract_color_lookupslime_extract type -> list(colour, rgb_code), built once from every slime_type.
last_processREALTIMEOFDAY of the last process tick, so cycles count real seconds even when the server is lagging.

running_particle_keyKey used with add_shared_particles/remove_shared_particles for the current cycle, null when idle.

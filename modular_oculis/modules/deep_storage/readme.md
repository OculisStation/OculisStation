## \<DEEP STORAGE>

Module ID: DEEP_STORAGE

### Description:

This module is associated with the deep storage cargo system, intended to be primarily used during storm surges when shuttles are unavailable at the time.

The intention is that this system is not used often until the shuttles are unavailable, and all items here are limited per shift and cost a lot more, however arrive instantly from deep storage on station.

slime_mutation
/datum/slime_mutation

What a slime must eat or drain to mutate into another type.

Vars

latch_neededThe mobs still needed to be latch fed in order to mutate - stored as [mob type] = health drained (reduced as the slime eats said mobs)
latch_totalsSame deal for the drain requirements: [mob type] = health that had to be drained
mutates_intoThe slime type we pass on if we succeed
needed_itemsItems still needed to feed the slime in order to mutate. Items are removed as the slime eats them.
our_slimeThe slime working through this mutation.
syringe_blockedIf TRUE, then you can't get this color from a random mutator syringe
total_itemsThe full item list from before the slime ate any of it - scanners need it to show what's already done

Procs

has_progressWhether the slime has already eaten or drained anything toward this.
is_satisfiedTRUE once the slime has eaten and drained everything this needs.
on_latch_drainedCalled straight from the slime's own drain handler, so quotas update before it checks for an outcome.
